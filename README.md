# HOLOPLOT and AutoCAD Practice

A basic web practice edition of HOLOPLOT Plan and AutoCAD, built to practice anywhere, including on iPad Air with big touch controls and Mixing Station-style layered decks.

Live app: https://isaacred718.github.io/holoplot-autocad-practice/

This is a practice edition for learning. It is not the real HOLOPLOT Plan or Autodesk AutoCAD software, and it is not affiliated with HOLOPLOT or Autodesk.

## What is in it

HOLOPLOT side:
- 5 venue presets and a live SPL coverage heatmap (plan and side view) with a six-band legend
- 3 steerable arrays: azimuth, tilt, beam width, gain, and position, with faders and steppers
- Avg, Uniformity, and Spill readouts, 3 coverage drills, and 5 lessons

AutoCAD side:
- 2D canvas with Line, Circle, Rectang, Pline, Arc, Dimension, Text, and Erase
- Working command line (try LINE, CIRCLE, HELP, or coordinates like 10,10)
- Layers, SNAP, ORTHO, grid, properties, undo, Stage/Room/Speaker templates, 4 drafting drills, and 5 lessons

Both sides:
- Virtual tutor: highlight any text for a plain-language explanation, or tap a topic chip
- Legend and Keys & Labels toggles
- Momentary / Latched hover-value labels for beams and for dimensions and points
- A separate Edit Values mode: long-press a label (or tap Edit) to change a value live; Practice mode stays read-only

## Notes

- Static site served by GitHub Pages from index.html in this repo.
- Designs and progress save in browser local storage on the device you use, not on a server.
- Touch layout: full-width map/canvas on top, big layered control decks below, 56px primary controls, and inputs sized so iPad Safari does not auto-zoom.
